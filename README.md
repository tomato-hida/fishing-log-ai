# fishing-log-ai

**喋って記録して、AIが表に起こして、スプレッドシートが面で見せる。** 釣りの記録をそういう流れでやるための道具一式です。

釣り場では竿を置いて手帳を出す余裕はありません。でも投げながら「パンチライン、42」と言うことはできます。録音しておけば、帰ってから AI が文字に起こし、計測シートの行にしてくれる。あとはスプレッドシートが、ロッド・リール・ルアーの組み合わせごとに「毎回どれだけ飛ぶか」を表にしてくれます。

Google スプレッドシートと Apps Script だけで動きます。サーバーもアプリのインストールも要りません。

---

## 何が記録できるか

| シート | 1行の単位 | 中身 |
|---|---|---|
| 釣行 | 1回の釣行 | 場所、潮色、潮流、風、波、ベイト、時間、感想 |
| 計測 | 1投 | ロッド、リール、ルアー、飛距離 |
| 水深 | 1地点 | 場所、地点、沖からの距離、水深 |
| 計測集計 | ― | 断面A・B・C（下で説明） |

釣行と計測には、その日その場所の**雨量（前々日・前日・当日）・気圧・気温・最大風速**が自動で入ります。座標を一度登録しておけば、あとは何もしなくていい。

## 計測集計：3つの断面

ロッド・リール・ルアーは同時に全部を変えると何も分かりません。どれか固定して、残りで面を作ります。

- **断面A** リールを固定 → ロッドの硬さ × ルアー重量
- **断面B** ロッドを固定 → スプール径 × ルアー重量
- **断面C** ロッドとリールを固定 → ルアーの形状 × 重量

断面Cは「同じ10gでもミノーとシンペンでどれだけ違うか」を見るためのものです。作者の実測では、同じタックル・ほぼ同じ重さで、ミノー平均33m、シンペン平均45mと12mの差が出ました。重さだけで分けていたら、この差は平均37mという意味のない数字に埋もれます。

それぞれ **平均・投数・ばらつき（標準偏差）・最大** の4枚が並びます。見るのは平均です。考え方は [docs/設計の考え方.md](docs/設計の考え方.md) に。

## 始め方（5分）

1. Google スプレッドシートを新しく作る
2. **拡張機能 → Apps Script** を開く
3. `apps-script/setup.gs` と `apps-script/weather.gs` の中身を、それぞれ別のファイルとして貼る（左の「ファイル」の＋で追加）
4. 保存して、関数 `setupAll` を選んで実行（初回は権限の確認が出ます）
5. スプレッドシートに戻ると、7つのタブと上部の「釣りログ」メニューができています

そのあと：

- **タックルマスタ** の（例）を、自分のロッド・リール・ルアーに書き換える
- **場所マスター** に釣り場を登録する。座標は Google マップで右クリック → 座標をコピー、をそのまま貼る

## 釣り場での記録

[docs/喋り方.md](docs/喋り方.md) にまとめました。要点は2つだけ。

- 条件を変えたときだけ宣言する：「測定、コモド、カルコンSE、ビーフリーズ」
- あとは数字だけ：「32」「35」「30」。バックラッシュしたら「今の無し」

録音は何でも構いません。作者は Plaud NotePin と Insta360 X5 を併用しています。

## 録音から表へ

[prompts/](prompts/) に AI への頼み方を置いています。

1. [文字起こし.md](prompts/文字起こし.md) で録音を **要約させずに** 全部文字にする
2. [計測に起こす.md](prompts/計測に起こす.md) でそれを計測シートの行にする

1 が大事です。要約ツールは放っておくと「32m前後」と丸めてしまい、1投ずつの数字が消えます。

AI がスプレッドシートに直接書き込める環境（Claude の Google Sheets 連携など）なら、2 の結果をそのまま書き込ませることもできます。

## 気象データ

「釣りログ → 気象データを取得」で埋まります。データは [Open-Meteo](https://open-meteo.com/) の過去データ API（無料・登録不要）。

- 過去データは5日ほど遅れて確定します。直近の釣行は空のまま飛ばされ、後日もう一度実行すれば埋まります
- 「毎週自動で気象を取る」を一度実行すると、毎週月曜の朝に自動で取りに行きます

## ファイル構成

```
apps-script/
  setup.gs      全タブの組み立て、計測集計、メニュー
  weather.gs    気象データの取得
prompts/        AI への頼み方
docs/           設計の考え方、喋り方
sample/         見本データ（CSV）
```
