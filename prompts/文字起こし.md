# 文字起こし用の頼み方

録音ファイルを AI（Gemini、ChatGPT、Claude、Plaud の「Ask」など）に渡すときに使います。

**要約させないこと** がいちばん大事です。要約・議事録系のツールは、放っておくと「飛距離は32m前後」と丸めてしまい、1投ずつの数字が消えます。

---

## そのまま貼る文

```
この音声は釣りの最中の録音です。

要約・分析・整形は一切しないでください。
発話をそのまま、時刻付きで、すべて書き出してください。

- 言い間違い、言い直し、数字の訂正もそのまま残す
- 数字は聞こえたとおりに、算用数字で書く
- 発話のない区間（波の音、リールの音など）は「（環境音）」と1行にまとめる
- 聞き取れない箇所は「（不明）」と書く。推測で埋めない

次の言葉が出てきます。聞き取りの参考にしてください。
ロッド：［ここに自分のロッド名を並べる］
リール：［ここに自分のリール名を並べる］
ルアー：［ここに自分のルアー名を並べる］
場所：［ここに釣り場の呼び名を並べる］
```

## ファイルが大きすぎるとき

長時間の録画から音声だけ抜き出すと軽くなります。ffmpeg なら1行です。

```
ffmpeg -i 動画.mp4 -vn -ac 1 -b:a 64k 音声.mp3
```

64kbps・モノラルで、3時間でも80MB程度。音声認識にはこれで十分です。

## 録音のコツ

- 波の音は低い音域に広がっていて、離れたマイクだと声が埋もれます。マイクは胸元か口元に
- ウェアラブル録音機は「録れているつもりで止まっている」が一番多い失敗です。始めに一言しゃべって、録れていることを確かめてから釣り始める
- 動画を回しているなら、その音声が保険になります
