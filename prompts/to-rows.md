# 文字起こしから表に起こす頼み方

文字起こしの結果を、計測・釣行・水深シートの行にしてもらうときに使います。

---

## そのまま貼る文

```
次は釣りの最中の発話を文字起こししたものです。
これを3つの表の行に起こしてください。

## 計測（1行＝1投）
列：日付, 場所, ロッド, リール, ルアー, 投目, 飛距離m, 備考

- 「測定、〇〇、〇〇、〇〇」はロッド・リール・ルアーの宣言。次の宣言まで続いているとみなす
- 「ルアー、〇〇」はルアーだけの変更
- 数字だけの発話は飛距離（m）。同じ条件の中で1から投目を振る
- 「今の無し」「バックラッシュ」と言った投は行を作らない。理由が言われていれば、
  次の行の備考ではなく、表の下に「除外した投」として一覧で書く
- 言い直しがあれば最後の数字を採る

## 釣行（1行＝1回の釣行）
列：日付, 場所, ポイント, 潮色, 潮流向き, 潮流強さ, 風向, 風速, 波, 釣法, 開始時間, 終了時間, ベイト, 感想

- 発話から分かる項目だけ埋める。分からない項目は空欄。推測で埋めない
- 感想は、本人の言葉をなるべくそのまま短くまとめる

## 水深（1行＝1地点）
列：日付, 場所, 地点, 沖距離m, 水深m下限, 水深m上限, 測り方, 備考

- 「10〜11m」のような幅は下限と上限に分ける。1つの値なら下限だけ
- 測り方はディーパー／カウント／目測のどれか

## 出力
- 3つの表をそれぞれタブ区切りで出す（スプレッドシートにそのまま貼れるように）
- 最後に「確認が必要な点」を箇条書きで。数字が2回食い違っている、ルアー名が聞き取れない、など

日付：［釣行日］
場所：［場所マスターに登録してある呼び名］
ロッド・リール・ルアーの正式名：［タックルマスタと同じ書き方で並べる］

――文字起こしここから――
［貼る］
```

## ポイント

- **ロッド・リール・ルアーの名前は、タックルマスタと一字一句同じにする。** 違うと重量や硬さが自動で引けません。録音では「コモド」「カルコンSE」と略して言っても、ここで正式名を渡しておけば AI が揃えてくれます
- 「確認が必要な点」を必ず出させる。録音では同じ数字を2回言って食い違うことがよくあります
- AI がスプレッドシートに直接書き込める環境なら、「この内容を計測シートの最終行の下に追記して」と続ければ終わります。書き込むのは手で入れる列（日付〜備考）だけで、硬さや重量などの灰色の列は自動で埋まります
