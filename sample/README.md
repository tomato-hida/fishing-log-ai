# 見本データ

セットアップ直後のスプレッドシートに入れると、計測集計の面が埋まる様子を確かめられます。

| ファイル | 入れる先 |
|---|---|
| measure_sample.csv | 計測シート |
| log_sample.csv | 釣行シート |
| depth_sample.csv | 水深シート |

## 入れ方

1. 入れたいシート（たとえば「計測」）を開いて、**A1 を選択**しておく
2. **ファイル → インポート → アップロード** で CSV を選ぶ
3. インポート場所を **「選択したセルにあるデータを置換する」** にして「データをインポート」

CSV の見出しはシートの見出しと同じなので、1行目はそのまま上書きされるだけです。
「現在のシートに追加する」は、計測シートの自動の列が最下行まで数式を広げているため、1000行目より下に入ってしまうことがあります。

メモ帳で開いてコピー＆貼り付けすると、1行がまるごとA列に入ってしまいます。そうなったら、その範囲を選んで **データ → テキストを列に分割**（区切り文字：カンマ）で直せます。

## 確かめ方

ロッド・リール・ルアーの名前は、セットアップで入るタックルマスタの（例）と同じにしてあります。

計測集計の断面C（いちばん右のブロック）で「対象ロッド：（例）6.10ft MH ベイト」「対象リール：（例）標準ベイト 34mm」にすると、10gの列にミノー平均33m・シンペン平均45mが並びます。

数字は作者の実測をもとにしています。場所名は伏せています。
