# 見本データ

セットアップ直後のスプレッドシートに貼ると、計測集計の面が埋まる様子を確かめられます。

| ファイル | 貼る先 |
|---|---|
| measure_sample.csv | 計測シートの A2 から（A〜I列） |
| log_sample.csv | 釣行シートの A2 から |
| depth_sample.csv | 水深シートの A2 から |

見出し行は除いて貼ってください。ロッド・リール・ルアーの名前は、セットアップで入るタックルマスタの（例）と同じにしてあります。

貼ったあと、計測集計の断面C で「対象ロッド：（例）6.10ft MH ベイト」「対象リール：（例）標準ベイト 34mm」にすると、10gの列にミノー平均33m・シンペン平均45mが並びます。

数字は作者の実測をもとにしています。場所名は伏せています。
